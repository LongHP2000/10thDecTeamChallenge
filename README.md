## Project Description
An online collaborative project showcasing HTML and CSS skills for the Wednesday, December 10th, 2025 team challenge.

## Features
- Responsive design that works on desktop, tablet, and mobile devices
- Modern gradient color scheme
- Clean and professional layout
- Team member showcase
- Challenge information cards

## How to View
Simply open `index.html` in your web browser, or use a local web server:

```bash
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080/index.html`
